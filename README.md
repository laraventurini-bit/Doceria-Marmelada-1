2. Apresentação do projeto<br>

O que é o projeto?

A doceria Marmelada é uma vitrine virtual (e-commerce) criada para trazer
um ambiente aconchegante e acolhedor para os consumidores.<br><br>

Qual principal objetivo?<br>

O objetivo do site é ser intuitivo e prático, de modo que torne a experiência de
compra do consumidor mais rápida e fácil, usando os conceitos de
usabilidade para projetar um site que ajuda na rotina e possa ser acessado
rapidamente em qualquer momento.<br><br>

Qual problema busca resolver?<br>
O site da doceria Marmelada parte do cenário onde existe a loja física, sendo
esse o único meio de compra. Analisando a partir desse ponto, surge a
necessidade de trazer uma plataforma virtual para facilitar a compra sem
precisar do deslocamento, além de ser um meio que facilita o contato e
conhecer o estabelecimento antes da loja presencial.<br><br>

Por que esse projeto foi desenvolvido?<br>
Para prototipagem do projeto surgiu o desafio de criar uma plataforma inteira
do 0. A escolha de uma doceria vinha da ideia de que um local podia passar
a percepção de algo aconchegante. As escolhas, desde a paleta de cores até
a definição de combos e presentes, abrangem os conceitos para ornar com o
nome e a ideia que o site quer passar.<br><br>

3. Funcionalidades<br><br>
Principais funcionalidades:<br>
- Navegação pela página inicial (Home)<br>
- Sistema de identificação ( Login )<br>
- Catálogo digital e catalogação de produtos<br>
- Rodapé e canais de contato (Footer)<br><br>

4. Tecnologias utilizadas<br>
- HTML<br>
- CSS<br><br>

5. Estrutura<br>
1 Pasta geral ( projetoSite) - contém todos os arquivos que compõem
o site.<br>
2 Arquivo inicio.html - Página destinada para os código de HMTL e
CSS da página inicial do site.<br>
3 Arquivo login.html - Página destinada para os código de HMTL e
CSS da página de cadastro<br>
4 Arquivo cadapio.html - Página destinada para os código de HMTL
e CSS da página que contém os alimentos disponíveis para venda - o
catálogo.<br>
5 Imagens - Pasta separadas para imagens que não carregavam o
endereço de imagem.<br><br>

6. Como executar?<br>
Primeiramente, confira se o navegador está com a extensão Live Server
instalada. Após a instalação, basta clicar com o botão direito em cima do
arquivo e selecionar a opção “ Open with Live Server” e o site será aberto
no navegador.
